# Customer Churn Data Analysis

## Project Overview
This project focuses on analyzing customer churn data to identify the key factors that cause customers to leave a company. The analysis helps understand customer behavior and provides insights for improving customer retention.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Excel

## Dataset
The dataset contains customer information such as:
- Customer demographics
- Services used
- Monthly charges
- Contract details
- Churn status

## Analysis Performed
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Missing Value Handling
- Customer Segmentation
- Churn Rate Analysis
- Identifying factors affecting churn

## Key Insights
- Analyzed which customer groups have higher churn rates.
- Identified important features that influence customer decisions.
- Generated visual insights using charts and graphs.

## Conclusion
This analysis provides useful insights to help businesses understand customer churn and develop strategies to improve customer retention.
